# Сохранить видеопоток

Расширение для настольного Google Chrome. Запустите видео, нажмите значок расширения, выберите поток и нажмите «Сохранить файл». Оставьте вкладку сохранения открытой до окончания загрузки.

## Установка

[Скачайте ZIP](https://github.com/polevoimv-debug/stream-saver/archive/refs/heads/main.zip) и распакуйте его. Откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json. Сборка и сервер не требуются.

## Поддержка

Расширение ищет URL с расширениями .m3u8 и .mp4 среди недавних запросов страницы и источников видео, включая вложенные плееры. Для HLS поддерживаются завершённые незашифрованные записи MPEG-TS и fMP4 с совместной дорожкой звука. При выборе мастер-плейлиста расширение выбирает наибольший доступный битрейт среди подходящих вариантов. Части последовательно записываются на диск. Прямые MP4 сохраняются целиком.

Прямые эфиры, DASH, DRM, AES, диапазоны байтов и сборка раздельных дорожек не поддерживаются. Некоторые серверы требуют специальных заголовков или обновления временной ссылки. При ошибке вернитесь на сайт, перезапустите видео и повторите поиск.

Доступ к сайтам нужен для чтения источников во вложенных плеерах и загрузки с видеосерверов. Поиск запускается нажатием на значок. Адреса обрабатываются локально. Телеметрии нет.
