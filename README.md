# Сохранить видеопоток

Расширение для настольного Chrome сохраняет видео на компьютер. Если HLS-плеер предлагает озвучки отдельно от изображения, расширение собирает выбранные дорожки в один файл MP4.

## Установка и обновление

1. [Скачайте ZIP](https://github.com/polevoimv-debug/stream-saver/archive/refs/heads/main.zip) и распакуйте его в постоянную папку.
2. Откройте в Chrome `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение». Выберите папку, в которой лежит `manifest.json`. Сборка не требуется.

Для обновления закройте вкладку очереди после завершения загрузок. Скопируйте содержимое новой версии, включая папку `vendor`, в прежнюю папку расширения. На странице `chrome://extensions` нажмите значок перезагрузки на карточке «Сохранить видеопоток» и проверьте версию **0.2.0**. Если расширение уже загружено прямо из обновлённого проекта, достаточно нажать этот значок.

## Как сохранить фильм

1. Запустите видео на сайте и нажмите значок расширения в меню Chrome. Откроется вкладка сохранения.
2. Выберите качество по разрешению и битрейту, затем озвучку по названию или языку. Список озвучек зависит от выбранного качества. Если сайт передаёт готовый файл или единственный вариант, расширение показывает доступный вариант.
3. Проверьте название фильма. Расширение предлагает имя из метаданных или заголовка страницы. Его можно изменить перед сохранением.
4. Нажмите «Сохранить…», выберите место на диске. Чтобы добавить следующий фильм, запустите его на сайте и снова нажмите значок расширения. Задания выполняются по одному в общей вкладке.
5. Оставьте вкладку очереди открытой. В ней можно приостановить, продолжить или отменить текущую запись и отменить ожидающую. После отмены Chrome может оставить пустой новый файл.

Для раздельных дорожек процент показывает долю обработанной длительности видео при сборке MP4. Для исходного HLS он показывает ход загрузки по фрагментам, для прямого MP4 с известным размером — по байтам. При неизвестном размере MP4 индикатор остаётся без процента до завершения. Статус «100% · Сохранено» появляется после завершения записи на диск.

## Совместимость

Поддерживаются прямые MP4 и завершённые незашифрованные HLS-записи. Раздельные MPEG-TS и fMP4 с совместимыми кодеками объединяются в MP4 без перекодирования. Для видео с уже объединённым звуком сохраняется исходный контейнер TS или MP4. Отдельное аудио и список качеств определяются по мастер-плейлисту сайта. Если плеер загрузил только один вариант, доступны сведения этого варианта. Прямые эфиры, DRM, зашифрованные плейлисты, HLS с диапазонами байтов и DASH не поддерживаются. Если временная ссылка истекла, откройте видео на сайте заново.

Расширение запрашивает доступ к сайтам для чтения адресов из вложенных плееров и загрузки с видеосерверов. Поиск запускается кнопкой расширения. Обработка происходит в браузере. Название и адрес исходной страницы используются локально.

## Библиотека

В папке `vendor` находится неизменённый браузерный модуль Mediabunny 1.65.0 и лицензия MPL-2.0. [Исходный пакет той же версии](https://registry.npmjs.org/mediabunny/-/mediabunny-1.65.0.tgz).
